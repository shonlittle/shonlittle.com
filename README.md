# shonlittle.com

**Portfolio site for Shon Little – software engineer by day, actor by has-been.**

This is the source code for [shonlittle.com](https://shonlittle.com), a personal website showcasing the dual professional lives of Shon Little: an experienced software engineering leader and a classically trained actor (now retired, but still dramatic).

## ✨ About

The homepage offers visitors a choice between two paths:

- **Software Engineering**: Projects, experience, skills, and leadership in tech.
- **Acting**: Past performances, headshots, reels, and the occasional melodramatic anecdote.

## 🛠 Tech Stack

- [React.js](https://reactjs.org/)
- [Material UI (MUI)](https://mui.com/)

## 📦 Installation

```bash
git clone https://github.com/shonlittle/shonlittle.com.git
cd shonlittle.com
npm install
npm start
```
